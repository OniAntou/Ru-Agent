## [Unreleased]

### Removed

- **BREAKING(providers)**: Xoá 2 built-in OpenCode Zen và Kilo Gateway — Models.dev đã có cả hai (`opencode`, `kilo`, trùng base URL). Settings cũ tự migrate: `opencode`/`kilo`/`gguf` → `models.dev:opencode`/`models.dev:kilo`, model cũ chuyển vào field `model` chung; key cũ (accounts `api_key`/`kilo_gateway_api_key`) không còn dùng, phải nhập lại key mới (accounts `opencode_api_key`/`kilo_api_key`). Xoá 4 field khỏi `SettingsSnapshot` (`OpenCodeModel`, `KiloModel`, `ApiVariant`, `KiloReasoningEnabled`), key rows + dropdown options GUI, CLI `/backend` rows; default backend mới là OpenAI. Giữ nguyên OpenAI/Anthropic (Models.dev không có `api` cho 2 ông này) và Custom.

### Changed

- **gui**: **Dropdown Provider trong Settings tối giản hơn.** Bỏ input-well bo tròn bọc ô tìm kiếm (chỉ còn icon + textbox với hairline kẻ dưới), bỏ divider dày giữa hai nhóm, bỏ width cứng 280, header nhóm mảnh hơn (10.5, bỏ SemiBold), chấm key gọt còn 6px lề trái 0, dấu tick chọn hết Bold và n size 12 — hàng đồng bộ với hàng dựng runtime (`BuildProviderRowButton`). Không đổi hành vi: filter, sort A-Z, SIGNED IN/PROVIDERS, dot key, tick chọn giữ nguyên. Permission mặc định xác minh đã là `standard` trên mọi đường (backend run default, store CreatedDefault, GUI composer, CLI parser) — không thay đổi code.
- **feat(agent,trust)**: Model giờ là bộ lập kế hoạch tự chủ: một model step native có thể narration + nhiều tool call, read-only chạy song song tối đa 8, mutation/terminal giữ thứ tự, và approval resume rehydrate/re-evaluate durable batch mà không bắt model phát lại. Catalog preset canonical trong `RuAgent.Protocol` thay nhánh clean-workspace/Plan-Web cũ: `plan` auto read/Web và deny terminal/mutation; `standard` auto bounded-local mutation trong workspace và ask external/escape; `full_access` auto external structured file + arbitrary terminal nhưng vẫn deny structured protected path. Workspace trust nay explicit một lần cho mỗi canonical identity (GUI confirm hoặc CLI `--trust-workspace`); Full Access cần GUI gate hoặc CLI `--confirm-full-access` và terminal chạy bằng current Windows user, có thể truy cập ngoài workspace, không phải network/path sandbox. Migration v7→v8 chuyển preset textual, reset legacy về `plan`, yêu cầu trust lại; schema v10 giữ durable single-use preset snapshot/restore cho rollback.

- **fix(harness,persistence)**: **DPAPI thêm additional entropy gắn mục đích.** `harness_key.dat` và provider bootstrap trước đây `ProtectedData.Protect(..., optionalEntropy: null, ...)` — mọi process cùng user token unprotect được chỉ với 3 dòng code. - **fix(backend)**: **Outbox dispatch có fencing tại dispatcher.** Store đã chặn old-owner qua `claim_token`, consumer đã idempotent theo intent id (`AppendIfAbsentAsync`), nhưng dispatcher giữ lease cũ từng **ném** `outbox_mutation_conflict` khi ack sau khi lease bị re-claim. Nay cả Ack/Fail/Retry nhận `Conflict` → trả `LeaseLost` thay vì throw: message đã append (idempotent), history transitions là việc của owner mới. Test store-level khoá: ack/fail bằng token cũ → `Conflict`, token mới → `Acknowledged`.
- **fix(hosting)**: **Port race lúc khởi động Worker/Broker có giới hạn thử lại.** `FindFreeLoopbackPort` bind port 0 rồi release — cửa sổ giữa release và lúc con bind khiến child chết vì trùng cổng và host báo "did not become ready" không có lời giải thích. Nay khi readiness probe thất bại **kèm** child đã chết, host dọn generation đó và thử lại với cổng mới probing lại (tối đa 3 lần, chỉ khi Broker port là động — port cấu hình cứng không có gì để probe lại).
- **fix(host,gui,client)**: **Single-instance Mutex treo thay vì báo đã chạy.** `new Mutex(initiallyOwned: true, ...)` **block vô hạn** khi tiến trình khác đang giữ mutex: `RuBackend --managed-runtime` thứ hai đơ trong bootstrap (nhánh báo `public_host_already_running` không bao giờ chạy tới), một GUI chạy lần hai treo im thay vì đưa cửa sổ cũ lên, còn owner chết không release để lại abandoned mutex làm constructor kế tiếp ném `AbandonedMutexException` không được bắt. Nay acquisition zero-wait (`WaitOne(0)`), abandoned mutex được nhận thay vì ném, tên không tạo được (thiếu quyền `Global\`) đọc là "không acquire" để fallback `Local\` chạy thật.
