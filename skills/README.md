# Skills

Workspace `SKILL.md` prompt guidance (Claude/OpenCode/Pi shape): one directory
per skill with a `SKILL.md` carrying `name` + `description` frontmatter and a
markdown workflow body. Bodies are untrusted prompt guidance only: `/skills`
lists name + description, `/skill <name>` (and the model-side `skill` tool)
loads one body, and nothing here grants tools, scopes, paths, approvals, or
execution.
