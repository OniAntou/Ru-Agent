The release remains Preview, with no Stable publication. The initial Stable
packaging run was cancelled before packaging or tag creation after the channel
was clarified. Shared source and package versions are `0.1.2-preview.1`.

Initial CI whitespace checks found trailing blank lines in eighteen historical
verification pages. Only those blank lines were removed; the evidence was kept.
Local Python checks passed 210 tests with one POSIX-only skip; documentation
checks passed eight tests, Ruff passed, and route/runtime guards passed.

The first Preview release run
[39995384625](https://github.com/OniAntou/Ru-Agent/actions/runs/39995384625)
failed creating a run in the deny case of the trust-retry fixture:
`503 agent_store_unavailable`, before the fixture installed its failure trigger.
Twenty focused reruns (forty cases) passed. A new concurrency guard exercised
eight simultaneous initializers on each of ten fresh databases and passed.
These results do not establish the cause of the original storage failure.

The parallel CI run
[39995381350](https://github.com/OniAntou/Ru-Agent/actions/runs/39995381350)
found a cancellation race: after tool shutdown, the worker can advance the run
before Cancel commits its previously read version. Two deterministic regression
cases returned 409 before the fix. Cancel now rereads the durable projection,
preserves terminal results and retries version conflicts up to eight times
without repeating tool shutdown. Five new cases cover progress, cancelled and
completed results, retry success and exhausted contention.

After the initial cancellation fix, the full backend project passed 1,384 tests.
After adding retry-bound cases, the eight focused cancellation/trust tests passed.
The new fresh-schema concurrency guard passed independently. Logs are under
`%TEMP%`: `ru-v0.1.2-preview.1-release-failure.log`,
`ru-preview-ci-failure.log`, `ru-preview-trust-repro.log`,
`ru-preview-backend-after-cancel.log` and `ru-preview-fresh-schema-repro.log`.

Final CI, package build and disposable-machine installer acceptance remain
release gates. Earlier native UI and real-provider evidence is recorded in
[2026-10-23](2026-10-23.md); deterministic checks here do not repeat that evidence.
